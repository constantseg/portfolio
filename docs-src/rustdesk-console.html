Utiliser la console RustDesk

Appareils, carnets d'adresses, prise en main, transfert de fichiers, mode confidentialité.

Ce guide s'adresse aux techniciens qui prennent la main sur les postes de l'établissement. La console web et le client RustDesk utilisent le même compte : les carnets d'adresses sont partagés entre les deux.

1. La console web

Adresse : http://<IP_SRV_RUSTDESK>:21114/. Identifiants personnels fournis par l'administrateur.

Système → Appareils

Tous les postes enregistrés auprès du serveur. Pour chaque ligne :

  • le nom du poste ;
  • prendre la main avec le client RustDesk installé sur le poste du technicien ;
  • prendre la main dans le navigateur, sans client (dépannage depuis n'importe quel poste) ;
  • ajouter au carnet d'adresses d'un utilisateur.

Utilisateur → Carnets d'adresses

Les postes que chaque technicien suit (par exemple une salle, un bâtiment). Ce carnet est le même que celui affiché dans le client RustDesk connecté au même compte.

2. Configurer le client RustDesk du technicien

  1. Installer RustDesk sur le poste du technicien.
  2. Paramètres → Réseau → Serveur ID/Relais : coller la chaîne de configuration fournie par l'administrateur, puis Importer la configuration et Valider. La chaîne contient l'adresse du serveur et la clé publique.
  3. Paramètres → Compte → Connexion avec ses identifiants : le carnet d'adresses apparaît dans l'onglet correspondant.

La chaîne de configuration n'est pas reproduite ici : elle est transmise en interne avec les identifiants.

3. Pendant une prise en main

FonctionUsage
Contrôle à distanceÉcran, clavier et souris du poste.
Transfert de fichiersCopier un fichier vers ou depuis le poste sans passer par un partage.
TerminalInvite de commandes distante, sans afficher le bureau.
DiscussionFenêtre de chat avec l'utilisateur, visible de son côté.

4. Mode confidentialité

Il masque l'écran du poste distant pendant l'intervention. À utiliser dès qu'on intervient sur un poste en l'absence de l'utilisateur ou dans une salle (vidéoprojecteur, élèves présents), ou quand on saisit un mot de passe d'administration.

  • Ponctuellement : Paramètres d'affichage → Mode confidentialité pendant la session.
  • Automatiquement à chaque session : Paramètres → Affichage, option d'activation à l'ouverture.
  • Mode 1 : l'écran distant affiche un écran noir. Mode 2 : l'écran distant est éteint.
