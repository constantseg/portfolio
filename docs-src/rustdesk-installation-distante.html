Installer RustDesk à distance, ponctuellement

L'outil PowerShell et PsExec pour installer ou retirer le client d'un poste.

Objectif
Installer ou désinstaller le client RustDesk sur un poste précis sans attendre son redémarrage (la GPO n'agit qu'au démarrage) et sans se déplacer.
Outil
Script PowerShell avec une petite fenêtre WinForms (rustdesk-client-gestion.ps1), aussi compilé en .exe.

1. Prérequis

  • Être administrateur du domaine sur le poste cible.
  • PsExec (Sysinternals) sur le poste d'administration : télécharger l'archive, extraire PsExec.exe dans C:\Windows\System32\.
  • Le poste cible est allumé et joignable (partage administratif ADMIN$ accessible).

2. Utilisation

  1. Lancer RustDesk-client-gestion.exe (ou le script .ps1) sur le poste d'administration.
  2. Saisir le nom ou l'adresse IP du poste cible.
  3. Cliquer sur Installer ou Désinstaller.
  4. Une console s'ouvre : les lignes « error code 0 » et « error code 1 » sont normales. Attendre le message de fin.
  5. Le poste apparaît dans la console RustDesk (Système → Appareils).

3. Ce que fait l'outil

Installation : psexec \\<poste> -s -c -f <lanceur d'installation>. PsExec copie le lanceur sur le poste (-c -f) et l'exécute avec les droits SYSTEM (-s) ; le lanceur installe le client puis applique la même configuration que la GPO (serveur, clé publique).

Désinstallation : psexec \\<poste> -s cmd /c "C:\Program Files\RustDesk\rustdesk.exe" --uninstall.

4. Après une désinstallation

Supprimer le poste dans la console RustDesk (Système → Appareils) pour garder une liste à jour.

Cet outil répond à un besoin ponctuel. Pour installer une application sur un lot de postes, voir WinPloy, qui passe par WinRM plutôt que PsExec et vérifie l'intégrité des paquets.
