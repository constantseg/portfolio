Installer Gitea sous Docker

Gitea et PostgreSQL dans un fichier Compose, port SSH décalé, installation web.

Objectif
Héberger en interne un serveur Git (alternative à GitHub) pour versionner les configurations des switchs et le fichier Compose du serveur Docker.
Ports
Web 3000, SSH Gitea 222 (décalé pour laisser le 22 au SSH du serveur).

1. Prérequis

Un serveur Ubuntu Server avec Docker installé depuis le dépôt officiel (voir « Installer le serveur Docker et Portainer », étapes 1 et 2).

2. Préparer le dossier

sudo mkdir -p /opt/gitea
cd /opt/gitea
sudo nano docker-compose.yml

3. Fichier Compose

services:
  server:
    image: gitea/gitea:latest
    container_name: gitea
    environment:
      - USER_UID=1000
      - USER_GID=1000
      - GITEA__database__DB_TYPE=postgres
      - GITEA__database__HOST=db:5432
      - GITEA__database__NAME=gitea
      - GITEA__database__USER=gitea
      - GITEA__database__PASSWD=${GITEA_DB_PASSWORD}
    restart: always
    networks: [gitea_net]
    volumes:
      - gitea_data:/data
      - /etc/timezone:/etc/timezone:ro
      - /etc/localtime:/etc/localtime:ro
    ports:
      - "3000:3000"   # web
      - "222:22"      # SSH de Gitea, distinct du SSH du serveur
    depends_on: [db]

  db:
    image: postgres:15-alpine
    container_name: gitea_db
    restart: always
    environment:
      - POSTGRES_USER=gitea
      - POSTGRES_PASSWORD=${GITEA_DB_PASSWORD}   # le même que ci-dessus
      - POSTGRES_DB=gitea
    networks: [gitea_net]
    volumes:
      - postgres_data:/var/lib/postgresql/data

networks:
  gitea_net:
    name: gitea_net

volumes:
  gitea_data:
  postgres_data:

Le mot de passe de la base est placé dans un fichier .env à côté du Compose (lisible par root seulement), et pas en clair dans le fichier :

echo 'GITEA_DB_PASSWORD=<mot de passe long et aléatoire>' | sudo tee /opt/gitea/.env
sudo chmod 600 /opt/gitea/.env

4. Lancer et installer

sudo docker compose up -d
sudo docker ps      # gitea et gitea_db doivent être « Up »

Ouvrir http://<IP_SRV_GITEA>:3000. La page de configuration initiale s'affiche :

  • Base de données : laisser les valeurs, elles viennent du fichier Compose.
  • Titre du site : par exemple « Serveur Git réseau ».
  • Port du serveur SSH : 222. Sinon les URL de clonage SSH affichées par Gitea seront fausses.
  • URL de base : http://<IP_SRV_GITEA>:3000/.
  • Compte administrateur (en bas de page) : le créer maintenant et ranger le mot de passe dans le KeePass.

Cliquer sur Installer Gitea.

5. Vérifier

# depuis un poste d'administration
git clone ssh://git@<IP_SRV_GITEA>:222/<compte>/<depot>.git
