Procédure · SRV-RUSTDESK

Installer le serveur RustDesk et déployer le client

Conteneur RustDesk, clé publique, script d'installation, GPO au démarrage.

Objectif
Un serveur de prise en main à distance hébergé en interne : aucune session ne passe par les serveurs publics de RustDesk.
Image
lejianwen/rustdesk-server-s6 : serveur ID + relais + API et console web (projet github.com/lejianwen/rustdesk-api).
Sécurité
Connexions chiffrées obligatoires ; une règle du pare-feu bloque tout accès Internet au serveur.

1. Serveur

Ubuntu Server, nom d'hôte SRV-RUSTDESK, IP fixe <IP_SRV_RUSTDESK>, SSH activé. Installer Docker depuis le dépôt officiel (voir « Installer le serveur Docker et Portainer », étape 2).

2. Fichier Compose

sudo mkdir -p /data && cd /data
sudo nano docker-compose.yml
services:
  rustdesk:
    container_name: rustdesk-server
    image: lejianwen/rustdesk-server-s6:latest
    restart: unless-stopped
    ports:
      - "21114:21114"       # API web
      - "21115:21115"       # test NAT
      - "21116:21116"       # serveur ID (TCP)
      - "21116:21116/udp"   # serveur ID (UDP), indispensable
      - "21117:21117"       # relais
      - "21118:21118"       # WebSocket
      - "21119:21119"       # WebSocket relais
    environment:
      - TZ=Europe/Paris
      - ENCRYPTED_ONLY=1    # refuse tout client sans la clé publique
      - MUST_LOGIN=N
      - RELAY=<IP_SRV_RUSTDESK>:21117
      - RUSTDESK_API_RUSTDESK_ID_SERVER=<IP_SRV_RUSTDESK>:21116
      - RUSTDESK_API_RUSTDESK_RELAY_SERVER=<IP_SRV_RUSTDESK>:21117
      - RUSTDESK_API_RUSTDESK_API_SERVER=http://<IP_SRV_RUSTDESK>:21114
      - RUSTDESK_API_JWT_KEY=${JWT_KEY}              # fichier .env, 64 caractères aléatoires
      - RUSTDESK_API_KEY_FILE=/data/id_ed25519.pub
      - RUSTDESK_API_JWT_EXPIRE_DURATION=4h
    volumes:
      - ./data:/data        # clés et base : un seul dossier à sauvegarder
      - ./data/db:/app/data
    logging:                # rotation des journaux
      driver: json-file
      options: { max-size: "10m", max-file: "4" }
echo "JWT_KEY=$(openssl rand -hex 32)" | sudo tee /data/.env && sudo chmod 600 /data/.env
sudo docker compose up -d

3. Après le premier démarrage

# mot de passe de la console web (à ranger dans le KeePass)
sudo docker exec -it rustdesk-server ./apimain reset-admin-pwd '<mot de passe>'

# clé publique à donner aux clients
sudo cat /data/data/id_ed25519.pub

La console web est accessible sur http://<IP_SRV_RUSTDESK>:21114/.

4. Déploiement du client par GPO

Sur le partage de distribution (\\<serveur-fichiers>\Distributions\RustDesk\) :

  • rustdesk.exe : l'installeur officiel du client ;
  • install-RustDesk.bat : le script qui installe puis configure le client.

Le script ne réinstalle pas si le client est déjà présent, puis applique la configuration à chaque démarrage :

if not exist "C:\Program Files\RustDesk\rustdesk.exe" (
    copy /Y "%SOURCE%" "%TEMP%\rustdesk_install.exe"
    "%TEMP%\rustdesk_install.exe" --silent-install
    timeout /t 15 /nobreak >NUL          &:: laisser le service démarrer
)
set RD="C:\Program Files\RustDesk\rustdesk.exe"
%RD% --option custom-rendezvous-server %SERVEUR%
%RD% --option relay-server %SERVEUR%
%RD% --option api-server http://%SERVEUR%:21114
%RD% --option key %CLE_PUBLIQUE%
%RD% --option verification-method use-permanent-password
%RD% --option enable-random-password 0

Le script est converti en exécutable (Bat To Exe Converter), puis lancé par une GPO ordinateur (Configuration ordinateur → Stratégies → Paramètres Windows → Scripts → Démarrage) liée à l'OU des postes. On teste d'abord sur une OU de test avec une GPO dédiée.

Limite connue. Le mot de passe permanent du client est défini dans ce script. Convertir un .bat en .exe ne le protège pas : l'exécutable se décompresse et le partage est lisible par tous les postes. Piste d'amélioration : n'autoriser la prise en main qu'aux comptes connectés à la console (carnet d'adresses), ou réduire les droits de lecture du partage au seul compte ordinateur.

5. Vérifier

  • Après redémarrage d'un poste de test, il apparaît dans la console web, menu Appareils.
  • Une prise en main depuis la console fonctionne, avec le cadenas « chiffré » dans la barre RustDesk.
