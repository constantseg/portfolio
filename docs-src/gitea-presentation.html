Présentation de Gitea

À quoi sert Git pour les configurations, et comment lire l'historique d'une sauvegarde.

Git, en une phrase

Git conserve l'historique complet de chaque modification d'un fichier. Gitea est le serveur Git interne de l'établissement, avec une interface web proche de GitHub.

Pourquoi l'utiliser pour les configurations

BesoinCe que Git apporte
TraçabilitéChaque modification est datée, avec son auteur et un message.
Retour arrièreUne configuration d'avant-hier se retrouve en deux clics, après une erreur ou le remplacement d'un switch.
DiagnosticLa comparaison de deux versions montre exactement les lignes modifiées : utile quand « quelque chose a changé » sur le réseau.

Se repérer dans l'interface

Page d'accueil

  • À gauche, le fil des dernières modifications sur tous les dépôts.
  • À droite, la liste des dépôts auxquels on a accès.

Un dépôt

  • La liste des fichiers, dans leur dernière version.
  • Le lien Commits (« N commits ») : la liste des versions. Pour la sauvegarde des switchs, un commit = une nuit où au moins une configuration a changé.

Un commit

Cliquer sur un commit affiche, fichier par fichier, les lignes ajoutées en vert et retirées en rouge. Le bouton Parcourir les fichiers montre le dépôt tel qu'il était à ce moment-là.
