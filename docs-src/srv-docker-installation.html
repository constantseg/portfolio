Installer le serveur Docker et Portainer

Ubuntu Server, Docker depuis le dépôt officiel, Portainer CE par Docker Compose.

Objectif
Préparer le serveur qui héberge tous les conteneurs de l'établissement, administrés depuis Portainer.
Prérequis
Un serveur Gitea en service (procédure « Installer Gitea sous Docker »).
Suite
Partie 2 : « Relier Gitea et Portainer ».

Les adresses IP, les noms de partage et les identifiants réels ont été remplacés par des valeurs génériques (<IP_SRV_DOCKER>, etc.). Les captures d'écran de la version interne ne sont pas reprises.

Une fois le serveur démarré, mettre le système à jour :

sudo apt update && sudo apt upgrade -y

2. Installer Docker depuis le dépôt officiel

Le paquet docker.io d'Ubuntu est souvent en retard : on utilise le dépôt de Docker.

# Clé GPG officielle de Docker
sudo apt install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Ajout du dépôt
sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Signed-By: /etc/apt/keyrings/docker.asc
EOF
sudo apt update

# Paquets Docker
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# Démarrage automatique
sudo systemctl enable --now docker

Vérification : sudo docker run --rm hello-world affiche « Hello from Docker! ».

3. Installer Portainer CE

Les fichiers Compose sont rangés sous /opt/docker-compose/<application>.

sudo mkdir -p /opt/docker-compose/portainer/portainer_data
cd /opt/docker-compose/portainer
sudo curl -L https://downloads.portainer.io/ce-lts/portainer-compose.yaml -o portainer-compose.yaml
sudo nano portainer-compose.yaml

Dans le fichier téléchargé, supprimer la ligne qui publie le port de l'agent Edge (8000:8000) : il ne sert pas ici et c'est un port ouvert de moins.

sudo docker compose -f portainer-compose.yaml up -d
sudo docker ps          # le conteneur portainer doit être « Up »

4. Premier accès

  1. Ouvrir https://<IP_SRV_DOCKER>:9443 (certificat auto-signé à accepter).
  2. Créer le compte administrateur Portainer. Le mot de passe est rangé dans le KeePass du service.
  3. Cliquer sur Get Started, puis sur l'environnement local (Live connect).

Portainer impose de créer le compte administrateur dans les minutes qui suivent le démarrage. Passé ce délai, il faut redémarrer le conteneur : sudo docker restart portainer.
